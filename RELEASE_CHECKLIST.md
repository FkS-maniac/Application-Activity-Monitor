# Проверка перед stable 1.0.0

- [ ] Чистая установка на Windows 11, Python 3.13.
- [ ] Проверка на Windows 10 либо явно ограничить список поддерживаемых ОС.
- [ ] Unit-тесты проходят на Windows.
- [ ] GUI открывается, все категории и пустые отчёты работают.
- [ ] Фоновый/свёрнутый процесс учитывается без переключения фокуса.
- [ ] PID 0/4, SessionID=0 и известные OS-background не попадают в новые записи.
- [ ] WMI работает при доступных правах; access denied корректно включает polling.
- [ ] Указан приблизительный конец при polling, нет обещаний точного stop.
- [ ] Сброс 10 раз не удаляет историю и не дублирует запуск.
- [ ] Новые процессы сохраняются после сброса.
- [ ] Перезапуск процесса с новым create_time создаёт новую сессию.
- [ ] TTL/backoff не повторяет чтение без срока.
- [ ] Hot-reload allowlist и категорий применяет изменения.
- [ ] Сохранение CSV, TXT, redaction обычных и JSON путей.
- [ ] Трей: открыть/пауза/стоп/выход, корректное закрытие.
- [ ] Второй экземпляр заблокирован mutex, в том числе две копии папки.
- [ ] CPU/RAM/диск измерены на 300+ процессах и часовой работе.
- [ ] Проверена восстановимость после принудительного завершения.
- [ ] EXE собран и проверен отдельно от исходного запуска.
- [ ] Архив не содержит личные логи, базу, .venv, секреты и __pycache__.
- [ ] Dependency licensing проверено для выбранного способа распространения EXE.
- [ ] После выполнения исправлений и повторных тестов сменить версию на stable.
